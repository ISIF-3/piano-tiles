# 클래식 피아노 타일

작곡가 42명의 클래식 곡 867곡을 게임(피아노 타일)으로 연주하거나 감상하는 웹앱입니다.
아이폰 Safari에서 열고 "홈 화면에 추가"하면 앱처럼 쓸 수 있고, 한 번 열어 두면 오프라인에서도 동작합니다.
